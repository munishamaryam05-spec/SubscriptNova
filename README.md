# SubscriptNova

### Simplify Subscriptions. Automate Billing. Understand Revenue.

SubscriptNova is a subscription management and revenue automation platform designed to help businesses manage customers, products, subscription plans, billing cycles, invoices and revenue performance from one place.

## Overview

Managing multiple subscriptions, recurring payments and invoices can become complicated for businesses. SubscriptNova brings these operations together through a centralized dashboard with tools for subscription tracking, billing management and revenue insights.

## Key Features

### 1. Dashboard
- Monitor Monthly Recurring Revenue (MRR).
- Track active subscriptions and revenue performance.
- View recent activities and invoices.
- Visualize subscription and revenue trends.

### 2. Customer Management
- Add, edit and manage customer records.
- View customer profiles and associated subscriptions.
- Track customer invoices and payment history.

### 3. Product Management
- Manage products and product variants.
- Track product pricing and margins.

### 4. Subscription Plans
- Create flexible subscription plans.
- Support daily, weekly, monthly and yearly billing frequencies.
- Configure subscription policies.

### 5. Quotations
- Generate customer quotations.
- Add multiple products and apply discounts and taxes.
- Track quotation statuses.

### 6. Subscription Management
- Create and manage subscriptions.
- Track subscription status and billing dates.
- Manage subscription lifecycle actions.

### 7. Invoices and Billing
- Generate invoices.
- Manage billing cycles.
- Track paid, pending and overdue invoices.
- Prevent duplicate billing records.

### Upcoming Features
- Payments and Discounts Management.
- Revenue Leakage Detection.
- Advanced Revenue Analytics.

## Getting Started

### Prerequisites
- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project:

```bash
cd SubscriptNova
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
